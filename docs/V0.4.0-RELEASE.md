# DeenPath 0.4.0 development update

Application ID remains `org.salahguard.app`, version code 12. The existing development signing identity and user databases are retained. The project directory remains SalahGuide, as requested. Hosting deployment is deferred.

## User-visible changes

- Help & About contains nine short purpose statements beneath Reminders and Widgets. Beneath the daily-prayer introduction, **Made By Syed Anas Ali Askari** links the name to an email draft addressed to syedanasaliaskarivu@gmail.com. Nothing is sent automatically.
- Gardens and Freeze Points awards/UI are retired. Gems and My Collection replace them. Historical records/legacy balances are kept; normal recorded worship and avoidance streak statistics remain. Old widget component identities now display Gems/Collection, preserving launcher bindings.
- Completion receipts show actual granted Gems, including native notification and PDF actions. Duplicate completion, close and snooze grant nothing. Corrections display only the real increase.
- Counter saves no longer wait for a full reminder rebuild. Reminder work is coalesced after commits; unchanged counter progress does not rebuild prayer schedules. Tasbih count/completion save together, and the card updates immediately. Tapping the card heading/text/background or pressing Space/Enter counts; edit, attachment and other controls retain their own actions. Completed-card swipes retain their previous behavior.
- Timed and lock-screen Enforcers keep actions in a fixed footer above navigation/gesture space, including Remind me later; long bilingual text scrolls separately. No app-opening/Usage Access trigger has been added.
- Charity penalties keep amount/currency private, with a 24-hour deadline and generic notifications at +4/+8/+12/+16/+20 hours. Giving charity, corrections and deletion suppress further alerts. Expiry does not claim that an obligation was performed, and no payment is processed.
- Gems ledger and Theme Studio support previews, free defaults, per-apply purchases, readable colors, wallpaper selection/replacement/removal, seasonal designs and optional effects with reduced-motion support.
- My Collection has search, rarity/category filters, unique/copy counts, duplicate indicators, Read/Listen/report controls and saved ownership. Pack opening supports a sealed packet, swipe/tap opening, Skip Animation, individual flips and interrupted-reveal recovery. Price remains 500 Gems for three distinct cards, with 55/30/12/3 per-draw rarity weights.
- Full-screen stories support complete English/proper Urdu editions, references, RTL, text size, reading-position retention, Android TTS playback controls and explicit missing-voice installation guidance. No paid narration API is used.

## Backend and data

Additive PHP/MySQL migrations 004 and 005 introduce the canonical Gems ledger, purchases, shared definitions/artwork, owned copies, reports/moderation, generation budgets/queue, Google identity challenges and separately reviewed bilingual story editions. Server transactions and stable operation IDs prevent duplicate charges and rewards; client balance totals are not authoritative. Private Composer dependencies and CLI worker setup are documented in EXTERNAL-SETUP.md.

SQLite schema 5 retains long owned stories separately from the frequently rewritten app snapshot. Owned text is not evicted with image caches. Only catalog metadata and necessary selected/owned content are fetched; no global story bank or generated audio is bundled in the APK.

## External limitations

The owner explicitly deferred hosting upload and selected setup instructions for real Google/Gemini/Cloudflare credentials. No live hosting/database was modified, provider key copied from the phone, paid billing activated or real AI call made. The approved future endpoint is documented, but the hosted service and verified content library are not live-qualified. New packs remain unavailable without a sufficiently populated independently reviewed library; no Gems are spent while it is unavailable. Synthetic fixtures are confined to tests.

Actual Google consent/sign-in/link/reinstall recovery, live generation quality/rights/free-tier qualification, and independent English/Urdu/source/art review remain deployment work. See AI-CARD-PROVIDER-RESEARCH.md for provider qualification details.

Android may delay reminders under Doze/OEM suspension. Full-screen display is attempted only through the existing explicit screen-wake option and Android's permission gate, with normal notification fallback. The old alarm-clock scheduling workaround was removed; no accessibility or app-usage monitoring was introduced. A one-minute interval is a requested cadence, not a guarantee of one-minute delivery while the phone sleeps. See V0.4.0-TESTING.md for observed device results and untested cases.

Install the supplied debug APK as an update, never by clearing data or uninstalling the existing app. The preserved v0.3.8 deliverables remain untouched reference backups. Direct APK downgrade after SQLite schema 5 is unsupported; preserve backups and prefer a forward fix. Keep the existing signing key secure; private signing keys are excluded from delivery archives. Detailed checks, APK sizes and remaining physical tests are recorded in V0.4.0-TESTING.md.
