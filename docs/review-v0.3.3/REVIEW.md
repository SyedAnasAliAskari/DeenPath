# v0.3.3 screen review

Screenshots cover the built frontend in a clean browser context at 390px: Home (current/next prayer and compact daily summary), Prayer Today, monthly Calendar, mobile Report, categorized More and Reminders. Additional report screenshots exercise 320px, large text, dark mode, English, Urdu and Arabic. Existing browser tests also cover routine editing, attachments, personal repentance, Qibla/Travel spacing, dialog dismissal and all five navigation tabs.

The screenshots were inspected visually. Report values stack into labeled cells on narrow screens; prayer times and completion controls occupy distinct areas; Calendar dates open their real saved records. Full-page screenshots include the fixed navigation bar at its captured viewport position; the bar remains fixed while scrolling and the page has bottom safe-area padding.

These published screenshots are browser captures. Additional native Enforcer and launcher captures were reviewed locally on the connected Infinix phone; private Home/other-app captures are excluded from the source archive. Physical compass calibration is still unverified. See DEVICE-QA.md. The source recording observations and limits are in ../V0.3.3-AUDIT.md.
